Чтобы цикл заработал, настройте:

    1Яндекс Почта

    Для внешней почты нужен отдельный app-пароль Яндекса (не основной пароль).

    2Google Таблица

    Открыть таблицу ↗

    Дайте сервисному аккаунту доступ к таблице (Share → email сервисного аккаунта) с правами редактора.

    3Правила «текст → статус»

    Лого и причина берутся из темы письма «Согласование <лого> - артикул - причина» (например «Согласование RRE - 1068050730 - вмятина»). Если столбец задан — статус меняется, только когда в строке совпали все указанные поля (артикул, лого, причина) с письмом.

    Обновит столбец, только если в нём сейчас это значение. Иначе письмо останется непрочитанным.

    4Второе правило статуса

    Если задан столбец инвойса — статус меняется только когда совпали и артикул, и номер инвойса в найденной строке.

    Правило №2 работает независимо от правила 03 (свой отправитель, лист и столбцы).

    Если здесь указана почта — ответы с неё правило №2 не обрабатывает. Указанная почта обрабатывается отдельным правилом 03 (своё правило «текст → статус»).

    6Перемещение писем

    Перемещается только успешно обработанное письмо (статус изменён), и только если включено «Отмечать прочитанным».

    Названия применяются сразу при вводе. Менять могут только администраторы.
