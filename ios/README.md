# BioTime — iOS-версия (WebView)

Нативная iOS-обёртка вокруг веб-приложения BioTime — прямой аналог Android-WebView
обёртки. Приложение открывает адрес вашего сайта в полноэкранном `WKWebView`
(без адресной строки), вход происходит через сессию шлюза Битрикс24 (куки хранит
сам `WKWebView`), обработка «чёлки»/Home-индикатора учтена.

## Структура

```
ios/
├── BioTimeWebView.xcodeproj/        # Xcode-проект
└── BioTimeWebView/
    ├── AppDelegate.swift            # точка входа
    ├── SceneDelegate.swift          # окно приложения
    ├── ViewController.swift         # WKWebView — сам контейнер
    ├── Info.plist                   # конфигурация, ATS, имя
    ├── Assets.xcassets/             # иконка приложения (AppIcon)
    └── Base.lproj/LaunchScreen.storyboard
```

## Шаг 0. ВАЖНО: вставьте адрес вашего приложения

В файле `BioTimeWebView/ViewController.swift` откройте строку
`private let appURL = URL(string: "...")!` и замените `https://app-EXAMPLE...`
на **реальный адрес вашего приложения VibeCode** — тот самый, что открывается
в браузере и в Android-обёртке (например `https://app-<id>.vibecode.bitrix24.tech`).

## Шаг 1. Сборка на Mac

Вам понадобится **macOS с Xcode** (бесплатно из App Store).

1. Скопируйте папку `ios/` на Mac (например, через AirDrop, почту или Git).
2. Дважды кликните `BioTimeWebView.xcodeproj` — откроется Xcode.
3. Выберите симулятор iPhone (слева вверху) и нажмите **Run** (▶).

> Для запуска **на реальном iPhone**:
> 1. Подключите iPhone кабелем и выберите его как устройство в Xcode.
> 2. Откройте `Signing & Capabilities` → поставьте галочку *Automatically manage
>    signing* и выберите свою **Team** (нужен Apple ID; бесплатная команда
>    создаётся автоматически при входе в Apple ID в Xcode).
> 3. Нажмите **Run**. На iPhone подтвердите установку (Открыть приложение из
>    разработчика) в Настройках → Основные → Управление устройством/профиль.

## Шаг 2. Если хотите распространять (TestFlight / App Store)

Без Apple Developer-аккаунта ($99/год) приложение запускается только на вашем
iPhone. Чтобы выпустить для команды:

1. Оформите **Apple Developer Program** (https://developer.apple.com) —
   нужно на вашей стороне, в среде Код/Коворк это сделать нельзя.
2. В Xcode `Signing & Capabilities` выберите эту команду.
3. Меню **Product → Archive**, затем в Organizer выберите **Distribute App**.
4. Для команды удобнее всего **TestFlight** (не нужен App Review, до 100
   внутренних тестировщиков и до 10 000 внешних) или **App Store Connect**.

## Полезные замечания

- **Вход и админ-доступ.** Обёртка открывает тот же адрес, что и веб/Android,
  поэтому и права работают так же (включая исправление доступа администратора,
  сделанное на сервере). Если внутри WebView у кого-то нет админ-панели —
  причина та же, что и раньше (роль MEMBER в сессии шлюза), лечится на сервере.
- **Обновления.** Приложение всегда открывает актуальную версию с сервера —
  пересобирать iOS-версию после правок сайта не нужно.
- **Иконка.** Используется `ios-icon-1024.png` из корня проекта (1024×1024,
   обязателен для App Store). При желании замените на свою — просто положите
   файл 1024×1024 в `AppIcon.appiconset` и обновите `Contents.json`.

## Фоновый трекинг геолокации (водитель на карте)

Обёртка отправляет координаты водителя на готовый эндпоинт BIOTIME
`POST /api/drivers/location` — так админ видит его на карте «Трекинг»
даже при свёрнутом приложении (iOS-аналог Android-обёртки).

- `LocationTracker` (файл `BioTimeWebView/LocationTracker.swift`) собирает
  координаты через `CLLocationManager` (точность `bestForNavigation`) и шлёт их
  каждые ~15 секунд.
- В `Info.plist` добавлены описания доступа (`NSLocation*UsageDescription`) и
  фоновый режим (`UIBackgroundModes: location`); `AppDelegate` запускает трекер
  при старте.
- Адрес (в `ViewController.swift` и `LocationTracker.swift`) — реальный
`app-2660de1a180b.vibecode.bitrix24.tech`; держите их синхронно.

Что проверить при первом запуске:
1. iOS спросит доступ к местоположению — выбрать **«Разрешить всегда»**
   (для фона нужен именно «Всегда», не «При использовании»).
2. **Настройки → Приватность → Службы геолокации** → у приложения должно
   стоять **«Всегда»**.

Ограничение iOS: даже с фоном система может изредка прореживать обновления по
своим триггерам. Точность «секунда в секунду», как на Android, на iOS не
гарантируется — это ограничение ОС, а не кода.

## Распространение

В отличие от Android (APK по ссылке), iOS нельзя «раздать» приложение стороной:
обновления идут только через **App Store / TestFlight**, а не через self-update.
Для публикации нужен Apple Developer-аккаунт (см. раздел «Шаг 2» выше).
